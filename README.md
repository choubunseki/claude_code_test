# claude_code_test

## 3I/ATLAS 軌跡シミュレーション (`index.html`)

3例目の恒星間天体 **3I/ATLAS (C/2025 N1)** の太陽系内通過を、
双曲線ケプラー軌道から数値積分して 3D で可視化します。

### 起動方法

ブラウザの ES Module セキュリティ仕様により `file://` での直接オープンは
失敗します。リポジトリのルートで簡易 HTTP サーバを起動してください。

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。

### 操作

- **▶ 再生 / ❚❚ 一時停止** — 時間経過アニメーション
- **⟲ リセット** — 開始時刻 (近日点 −1 年) に戻す
- **タイムスライダー** — 任意の日付にジャンプ
- **速度** — 0.25× 〜 30×
- **追尾** — カメラを 3I/ATLAS に追従
- **軌跡線** — 通過済み経路の蛍光トレイル ON/OFF
- マウス: ドラッグで回転、ホイールでズーム
